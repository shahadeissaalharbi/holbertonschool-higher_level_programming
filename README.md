# Holberton School - Higher Level Programming

## About

This repository contains projects completed as part of the **Higher Level Programming** curriculum at Holberton School. It covers Python fundamentals and advanced concepts, SQL databases, JavaScript, and web frameworks like Flask, along with building REST APIs.

## Topics Covered

- **Python Basics**: Hello World, data structures, if/else, loops, and functions
- **Object-Oriented Programming**: Classes, objects, inheritance, and the "everything is an object" concept
- **Python Advanced**: Exceptions, ABCs (Abstract Base Classes), imports/modules, input/output, serialization, test-driven development
- **Databases**: SQL introduction and more advanced queries, Object-Relational Mapping (ORM)
- **JavaScript**: Warm-up exercises and DOM manipulation
- **Web Development**: Server-side rendering, Flask templates, and dynamic data display
- **REST APIs**: Building and consuming RESTful APIs
