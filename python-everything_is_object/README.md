# python-everything_is_object

## Description

This project explores a core concept in Python: **everything is an object**. Every variable, function, class, and even data types like integers and strings are objects in Python, each with their own identity, type, and value.

## Learning Objectives

- Why Python programming is awesome
- What does "everything is an object" mean
- What is the difference between a class and an object or instance
- What is the difference between immutable and mutable objects
- What is a reference
- What is an assignment
- What is an alias, and how do you use it
- How to know if two variables are identical
- How to know if two variables are linked to the same object
- How to display the variable identifier (which is the memory address in the CPython implementation)
- What is a reference counter, and how it works
- What is garbage collection, and how does it work in general and in Python specifically
